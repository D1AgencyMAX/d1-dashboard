# Fractional CTO Services — sales document

A branded "why choose us / why fractional works" prospectus for CEOs and boards,
styled to match the Digital One Agency dashboard (deep navy `#020617`, cyan `#22d3ee`
accents, Inter typeface).

## Files

| File | Use it for |
|------|------------|
| `fractional-cto-services.html` | The polished, branded deliverable. Open in any browser. **Print → Save as PDF** for a leave-behind. Print colours are preserved. |
| `fractional-cto-services.md` | Plain-text source for quick edits, pasting into email, or publishing to a web page / CMS. |

## Make a PDF

1. Open `fractional-cto-services.html` in Chrome.
2. `Ctrl/Cmd + P` → Destination **Save as PDF**.
3. Enable **Background graphics** so the dark theme renders.

## Things to personalise before sending

- Replace **"Ken"** with your full name / preferred signature.
- Swap the pull-quotes for real ones if you'd rather.
- Adjust the `$250k+` benchmark figure to your market if needed.
- Optionally name specific companies you owned in the track-record section
  (kept generic by default so it reads cleanly without disclosing client/brand names).
